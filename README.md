# 《双子堡垒：共守苍穹》（Twin Bastion TD）

基于 **Godot 4.7.2 + MoonRPG Engine** 构建的独立商业化像素风 **双人合作塔防（2P Co-op Tower Defense）** 完整项目。

## 核心特色
- **三种合作模式**：单人 + 智能 AI 搭档 / 同屏双人合作（2P Couch Co-op）/ 局域网联机（ENet LAN Co-op）
- **跨玩家塔防元素连携**：冰火超载（寒冰+法师）、箭兵破甲（箭塔+兵营）、双星共鸣（相邻双塔攻速+15%）
- **独立经济 + 一键转账支援（+50G）** 与 **双星合体超必杀【苍穹双星陨落】**
- **3 大战役关卡 + 6 项星级永久合作天赋树**（本地持久化存档）
- **零外部插件依赖** + 自动化测试套件 + 一键导出独立 `dist/TwinBastionTD.exe`

## 快速运行
- 开发态启动：`.\launch.ps1`
- 运行自动化测试：`.\launch.ps1 test`
- 导出独立 Windows 可执行程序：`.\build_windows.ps1`
