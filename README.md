# 《双子堡垒：共守苍穹》（Twin Bastion TD）

基于 **Godot 4.7.2 + MoonRPG Engine** 的像素风 **双人合作塔防**。两名玩家各自管理金币、塔和英雄，相邻建塔触发跨玩家连携，能量满后两人同时按键才能释放合体奥义。

## 玩法
- **三种合作模式**：单人 + AI 搭档（AI 会建塔、升级、支援金币、使用英雄技能、发起/响应合体）/ 同屏双人 / 局域网联机
- **4 种防御塔 × 3 级**：Lv1 建造 → Lv2 强化 → Lv3 二选一分支（共 8 种）
  - 箭塔：鹰眼狙击 / 连弩哨塔　法师塔：奥术尖塔 / 烈焰法坛
  - 寒冰塔：冰川之心 / 霜暴图腾　兵营：圣骑兵营 / 游骑兵营（兵营可设置集结点）
- **跨玩家连携**（只有 P1 与 P2 的塔相邻才会连上）：冰火超载、箭兵破甲、碎冰箭、奥术破甲、寒霜壁垒、双星共鸣
- **英雄技能**：P1 苍穹游侠【陨星箭雨】，P2 绯红圣骑【圣盾援军】；右键 / 手柄 RB 指挥英雄移动
- **双星合体【苍穹双星陨落】**：全场真实伤害 + 冰封 3 秒 + 全军回满血，需两名玩家在 5 秒内先后确认
- **大地图与路网**：每关是 1080×608 的世界（约为屏幕的 5 倍），3–5 个出怪口、数十条可走路线，
  路线在路口分叉又汇合；第 5 关地图中央的裂隙会在战斗中开门
- **会动脑子的敌人**：出发时按每条路的火力覆盖、长度和自身"狡猾度"选路，到每个路口还会重新判断；
  巨魔破城手反而专挑塔多的路；部分波次从随机出口进场，"侦察"波次会针对你们当前的塔种调整兵种
- **怪物会还手**：防御塔有耐久。哥布林弓手射塔，巨魔破城手停下来砸塔，爆裂蝠俯冲撞塔自爆，
  督军飞斧、黑曜魔王暗影弹、冰霜巨像咆哮都会伤塔。塔被打塌留下废墟，重建省三成；脱战慢慢回血，也能花钱修理
- **17 种敌人**：盾卫（物理减伤护盾）、萨满（治疗）、裂变史莱姆（死亡分裂）、刺客、石像鬼、弓手、破城手、爆裂蝠等；
  督军战吼加速、冰霜巨像冻结防御塔、黑曜魔王半血召唤并展开护盾
- **剧情**：序章、每关开场对话、战斗中的角色喊话、首领台词、胜负结语和终章；
  文本先用 plainspoken-writing 诊断，再按 qu-ai-wei 与 story-deslop 的规则改写
- **波次节奏**：第一波手动开始，之后自动倒计时；提前召唤，双方都能拿到递减的奖励金币
- **5 关战役 + 无尽模式**（通关第 3 关后解锁）、休闲 / 普通 / 困难三档难度
- **星级与天赋**：通关得 1★，城防过半得 2★，零漏怪（普通及以上）得 3★，困难通关额外得 1 顶王冠；
  共 8 项永久合作天赋，可随时洗点

## 操作
| | P1 | P2（同屏） |
|---|---|---|
| 光标 / 选塔位 | 鼠标 | 方向键 |
| 打开环形菜单 / 确认 | 左键 | Enter |
| 取消 | 右键 / Esc | 右 Shift |
| 移动英雄 | 右键点击地面 | `.` |
| 英雄技能 | Q（在鼠标处释放） | `/` |
| 支援 50G | T | `,` |
| 双星合体 | R | 右 Ctrl |
| 召唤下一波 / 加速 / 暂停 | Space / F / Esc | — |
| 移动视角 / 缩放 / 小地图 | WASD、鼠标推屏幕边缘 / 滚轮 / M（C 回到城堡） | 光标推到屏幕边缘自动跟随 |

手柄（自动分配，可热插拔）：左摇杆移动光标，右摇杆移动视角，A 确认，B 取消，X 英雄技能，Y 合体，RB 移动英雄，LB 支援，Start 暂停，Back 召唤波次。
同屏双人共用一个镜头：两人的光标分得太开时镜头会自动拉远；点击右上角小地图可以直接跳过去，屏幕边缘的箭头指向视野外的首领、快到城门的敌人和正在挨打的塔。
P1 也可以在鼠标悬停塔位时按 1–4 快速建塔。

## 美术与技术
- 全部单位都是用 ASCII 绘制的像素画，加载时自动描边；防御塔每个等级和分支都有不同造型
- 每关地形在载入时烘焙成一张贴图（大地图约 0.6 秒）：抖动着色的地面、带圆角拐弯的道路、桥、河流、裂谷、
  冰面、熔岩裂缝、双塔城堡和装饰物，上面再叠加动画层
- 界面图标同样在代码中绘制，不依赖系统 emoji 字体；不使用任何第三方插件

## 运行与验证
```powershell
.\launch.ps1            # 启动游戏
.\launch.ps1 test       # 自动化测试（逻辑、关卡布局校验、界面流程，并捕获脚本报错）
.\launch.ps1 balance    # 平衡模拟：每关 × 每档难度，由两个 AI 对战；可附加 stage= diff= seeds=
.\launch.ps1 shots      # 按脚本截取各场景截图，输出到 tools/out/
.\build_windows.ps1     # 导出 dist/TwinBastionTD.exe
```
测试使用独立的存档路径，不会覆盖玩家存档。关卡路网、塔位和出生点由 MapGraph 根据道路图自动生成，测试会校验每关至少 3 个出口、6 条路线和 18 个合法塔位。
当前平衡（4 种 AI 打法各跑一遍）：休闲全胜；普通除第 2 关为 3/4 外全胜，期间会丢塔；困难第 1 关 4/4、第 3 关 3/4、第 2、5 关 1/4、第 4 关 0/4。只有一个 AI 时每关都会失败，必须两人合作才能通关。
